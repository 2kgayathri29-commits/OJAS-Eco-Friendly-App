# OJAS – AI-Based Eco-Friendly Lifestyle Assistant

## Project Overview
OJAS is an Android application designed to encourage sustainable living by helping users make environmentally friendly lifestyle choices.

## Technologies Used
- Java
- XML
- Android Studio
- Firebase
- Room Database
- MVVM Architecture

## Key Features
- User registration and login
- Eco-friendly challenges
- Sustainable recipes and product suggestions
- Progress tracking and scoring
- Information about sustainable living

## Project Type
Academic Project – Bachelor of Computer Applications (BCA)
